# zemrakdesigns.com

Portfolio site for Sara Zemrak: compensation and workforce analytics.
Plain HTML and CSS, hosted on GitHub Pages. No build step.

- `index.html`: homepage
- `work/<project>/index.html`: one case study per project
- `assets/site.css`: all styles (colors and fonts live in `:root` at the top)
- `assets/band.js`: the interactive salary band in the hero
- `404.html`: not-found page

All data shown is public or clearly labelled synthetic. No employer data.
